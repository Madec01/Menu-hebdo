🍽️ Menu Hebdo v2.0

⚠️ Important

L'application utilise des modules JavaScript ES6 qui nécessitent un serveur HTTP pour fonctionner correctement (à cause de la politique CORS des navigateurs).

🚀 3 méthodes pour lancer l'application :

1️⃣ Méthode Python (Recommandée - Simple)

Si vous avez Python installé :

  1. Ouvrez un terminal dans ce dossier
  2. Lancez : python -m http.server 8000
  3. Ouvrez votre navigateur sur : http://localhost:8000

2️⃣ Méthode Node.js

Si vous avez Node.js installé :

  1. Ouvrez un terminal dans ce dossier
  2. Lancez: npx serve
  3. Suivez l'URL affichée (généralement http://localhost:3000)

3️⃣ Extension VS Code

Si vous utilisez Visual Studio Code :

  1. Installez l'extension "Live Server"
  2. Clic droit sur index.html
  3. Sélectionnez "Open with Live Server"

4️⃣ Version Standalone (Sans serveur)

Pour ouvrir directement dans le navigateur :

  1. Je vais créer une version standalone pour vous
  2. Cliquez sur le bouton ci-dessous pour la générer
  3. Puis ouvrez simplement le fichier dans votre navigateur
💡 Astuce : Une fois l'application lancée, elle fonctionnera hors ligne car toutes les données sont sauvegardées localement dans votre navigateur !
