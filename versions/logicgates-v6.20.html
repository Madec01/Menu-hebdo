📘 Guide des composants

Glisser le fond déplacer la vue  ·  Molette zoom  ·  Suppr effacer (survolé ou sélection)  ·  Échap annuler câble / désélectionner
Clic sur un composant = le sélectionner  ·  Maj + clic ou Ctrl + clic en ajouter / en retirer  ·  Maj + glisser le fond sélection rectangle
Maj + glisser un composant le dupliquer (l'original reste)  ·  Ctrl+C copier  ·  Ctrl+V coller  ·  Ctrl+X couper  ·  Ctrl+A tout sélectionner
Tirer la barre du bas d'un composant = régler son paramètre principal  ·  R tourner  ·  M miroir  ·  F recadrer sur le circuit  ·  N noms des composants  ·  survol = infobulle détaillée
Cliquer sur une entrée déjà câblée détache le fil (relâcher dans le vide le supprime).
Double-clic sur un fil ajouter une poignée ◆ déplaçable  ·  Double-clic sur ◆ la retirer  ·  Suppr fil survolé = suppression  ·  🪄 range les câbles automatiquement.
