# CRÉDITS VISUELS — CARILLON (agent A)

Tous les fichiers de `assets/sprites/`, `assets/tiles/`, `assets/ui/` et `assets/fonts/` sont des assets téléchargés, 
vérifiés avec Pillow, puis découpés, composés et recolorisés vers la palette du jeu avec Pillow. Aucun sprite n'est dessiné en code. 
Le réseau de la session ne laissant passer que GitHub, chaque pack a été récupéré depuis un dépôt Git qui embarque sa licence (preuve indiquée).

Palette de recolorisation : suie `#16130f`, tourbe `#2a241c`, mousse `#4a5540`, os `#d8cdb4`, bronze `#c9973f`, braise `#e0603a`, gris-silence `#8f8d93`.
