# 🚀 Comment voir l'application Menu Hebdo en ligne ?

## ✅ SOLUTION SIMPLE - Version Standalone

**Ouvrez directement ce fichier dans votre navigateur :**

📄 **`menu-hebdo-standalone.html`**

### Comment faire :
1. **Double-cliquez** sur le fichier `menu-hebdo-standalone.html`
2. OU **Clic droit** → Ouvrir avec → Votre navigateur (Chrome, Firefox, Edge, Safari)
3. C'est tout ! 🎉

✨ **Cette version fonctionne immédiatement sans configuration !**

---

## 📋 Autres Options (si vous voulez la version modulaire)

### Option 1 : Python (Recommandée)
```bash
# Dans le dossier Menu-hebdo
python -m http.server 8000

# Puis ouvrez : http://localhost:8000
```

### Option 2 : Node.js
```bash
npx serve

# Suivez l'URL affichée
```

### Option 3 : VS Code
1. Installez l'extension "Live Server"
2. Clic droit sur `index.html`
3. "Open with Live Server"

## ❓ Problèmes ?

### "L'application est cassée / moche"
→ **Utilisez `menu-hebdo-standalone.html`** au lieu de `index.html`

### "Rien ne se passe"
→ Assurez-vous d'utiliser un navigateur moderne (Chrome, Firefox, Edge, Safari)

### "Les données ne se sauvent pas"
→ Ne pas être en navigation privée
